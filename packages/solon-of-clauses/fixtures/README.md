A fictional Master Services Agreement between two made-up companies ("Kettle Labs Ltd" and "Fernhill Studio LLC") and a fictional customer-side clause playbook. Neither is a template or a recommendation; they are written to plant gaps so the demo, tests and evals have something to find. Not legal advice.

- `contracts/msa.md`: the agreement as text, with planted gaps, an undefined term ("Effective Date") and an unused definition ("Deliverables").
- `contracts/msa.docx`: the same text as a Word file, built from the .md, so both give the same findings and citations.
- `contracts/msa-v2-tracked.docx`: a later draft with one tracked change (payment within 60 days changed to 30) and one comment.
- `playbook.json`: the playbook, version 3.0.0; it passes the `playbook` schema.
