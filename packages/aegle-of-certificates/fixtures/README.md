Fictional certificates, domains, vendors and limits (example.com / example.net / example.internal). Not real companies or policies.

- `certificates.csv`, `certificates-previous.csv`: current and earlier inventory snapshots (for `aegle_diff_inventory`).
- `cois.csv`, `requirements.csv`: vendor COIs and a flat requirement list.
- `requirements.json`: a requirement profile with a stricter fictional "electrical" category.
- `coi-text/*.txt`: fictional certificate text in the style of a PDF text export, for `aegle_extract_coi`. Not real certificates; 555 phone numbers and example domains only.
