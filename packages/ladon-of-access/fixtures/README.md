Fictional people, agents and systems for demos and tests. example.com addresses only; no customer data.

- `access-export.csv` — current access export (people, an agent and a service account; includes a `last_rotated` column).
- `access-export-2026q3.csv` — the previous quarter's export, for `ladon_access_diff`.
- `hr-roster.csv` — HR roster with one leaver and managers.
- `ladon-policy.json` — review policy: a reviewer delegation and one segregation-of-duties rule.
- `recertification-filled.csv` — a sheet as reviewers might return it (some lines decided, one self-review, one invalid decision, some overdue), for `ladon_campaign_status` and `ladon_evidence_pack`.
