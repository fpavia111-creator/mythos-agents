Fictional packs whose docs drift on purpose, so the demo, tests and evals have something to find. There is no code in them.

- `kettle-of-notes/` ("Kettle Labs"): a package.json, a tools.json in MCP tools/list format, and a README, guide and SKILL.md that have drifted from them.
- `ladle-of-api/`: a recipe API client with an `openapi.json` (reserved example.com host), a README whose endpoints drift from it, a CHANGELOG.md with no entry for the package.json version, and `echo.config.json`, a config that passes the `docs_config` schema.
