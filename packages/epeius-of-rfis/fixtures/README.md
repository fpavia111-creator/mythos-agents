Fictional project ("Maple Street Clinic fit-out"), sheet numbers, spec sections and text extracts. Not real drawings or specifications. Company names are made up and marked "(fictional)".

- `documents.csv`: the drawing and spec index; `docs/`: text extracts of sheet notes and spec sections.
- `rfis.csv`, `submittals.csv`: the current logs (as of 2026-11-14). `submittals.csv` has an optional `ball_in_court` column.
- `rfis-previous.csv`: the RFI log as exported a week earlier (2026-11-07), for the week-over-week diff.
- `titleblocks/`: title-block text, one file per sheet. A-501 is on a newer revision than the index, A-601 is not in the index, and `scan-cover-page.txt` has no title block.
