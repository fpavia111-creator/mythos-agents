# Mythos Machine domain agents

> 이 번역은 Claude가 작성했으며 아직 원어민의 검토를 거치지 않았습니다. 내용이 다르면 [영어 README](README.md)가 우선합니다.

작은 MCP 에이전트 30개입니다. 각 에이전트는 **하나의 업무 프로세스**(접근 권한 검토, 은행 대사, ERP 이전 점검, 환불 분쟁 등)만 맡고, 그 밖의 일은 할 수 없습니다. 이미 내보내고 있는 파일을 읽고, 보고서를 사용자의 컴퓨터에 쓰며, 중요한 일이 일어나기 전에는 이름이 지정된 담당자를 기다립니다.

MIT 라이선스 · Node 20 이상 · 로컬 파일만 사용 · 자격 증명 불필요 · 의존성 없음

## 사용해 보기

```bash
npx -y ladon-of-access demo        # 가상 데이터로 접근 권한 검토
npx -y olympus-of-migration demo   # 가상 데이터로 ERP 이전 준비 점검
```

모든 에이전트에는 가상 파일로 실행되는 `demo`와 Claude Desktop, Claude Code, Cursor 등 MCP 호스트용 MCP 서버(`npx -y <agent> mcp`)가 있습니다. 각 에이전트의 도구는 해당 README(영어)를 참고하세요.

## 파일과 언어

CSV, TSV, 세미콜론·세로선 구분 텍스트, Excel `.xlsx`, JSON, JSONL을 읽습니다. 12개 에이전트는 Okta, Microsoft Entra ID, Google Workspace, NetSuite, QuickBooks Online, Xero, Stripe, Shopify, Salesforce, Ramp, 미국 은행 5곳 등 39가지 내보내기 형식을 열 이름으로 인식합니다. 그중 2가지는 공급업체 문서와 대조했고, 나머지는 해당 내보내기에 대한 지식을 바탕으로 작성했으며, 어느 것도 실제 계정으로 테스트하지는 않았습니다.

한국 시스템에서 내보낸 파일도 그대로 읽습니다: 한국어 열 이름(`금액`, `거래처`, `사업자등록번호`, `적요`, `차변`, `대변`, `입금`, `출금` 등), EUC-KR(CP949)과 UTF-16 인코딩, `1,200원`이나 `₩1,200` 같은 금액, `2026년 11월 14일`·`2026. 11. 14.`·`2026.11.14` 같은 날짜, `(주)`·`㈜`·`주식회사`·`유한회사`가 붙은 회사명. `--lang ko`를 지정하면 승인 페이지, Olympus 이전 준비 보고서, Ladon 재인증 요약과 증빙 페이지가 한국어로 표시됩니다. 결과, 코드, CSV 파일은 영어로 유지됩니다.

## 모든 에이전트가 따르는 규칙

- 알 수 없는 도구는 차단됩니다. 기본 결정은 차단입니다.
- **Auto**는 기본적으로 꺼져 있고 작업별로 켭니다. 단계 수와 지출 한도, 긴급 정지가 있습니다.
- 운영 전환, 권한 회수, 개인정보 삭제, 자금 이동, 법적 구속력이 있는 발송, 운영 배포는 Auto에서도 항상 이름이 지정된 담당자의 클릭이 필요합니다. 에이전트가 기억하는 내용을 바꾸는 것도 마찬가지입니다.
- 메모리가 있는 에이전트(Olympus와 Ladon)는 이름이 지정된 담당자가 승인한 사실만 사용하고, 각 결과에 어떤 사실을 썼는지 밝히며, 점검을 느슨하게 만드는 내용은 학습할 수 없습니다.
- 모든 결정은 해시 체인 JSONL 감사 로그에 기록되며, 키를 지정하면 서명됩니다.
- 파일 속 텍스트는 데이터로 취급합니다. 스프레드시트 수식, 원시 HTML, ID 안의 `../`는 출력할 때 무력화하고, AI 모델을 겨냥한 문구("ignore previous instructions")를 인용한 결과에는 표시를 붙입니다. 이 표시는 경험적 방법이지 필터가 아닙니다.

## 이 에이전트가 아닌 것

- 실시간 연동이 아닙니다. 내보낸 파일만 읽고 사용자의 시스템에 로그인하지 않습니다.
- 법률·세무·회계·감사 자문이 아니며, 무엇도 인증하지 않습니다.
- 완전 자율이 아닙니다. 위의 작업은 매번 담당자를 기다립니다.
- 어느 나라의 법률, 세법, 신고 양식에 대해서도 주장하지 않습니다.
