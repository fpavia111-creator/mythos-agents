# Mythos Machine domain agents

> この翻訳は Claude が作成したもので、ネイティブ話者による確認はまだです。内容が異なる場合は[英語版 README](README.md) が優先します。

30 個の小さな MCP エージェントです。それぞれが**ひとつの業務プロセス**（アクセス権の棚卸し、銀行勘定の照合、ERP 移行のチェック、返金・チャージバック対応など）だけを担当し、その範囲の外では何もできません。すでにエクスポートしているファイルを読み、レポートをお使いのコンピューター上に書き出し、重要な操作の前には必ず名前のある担当者を待ちます。

MIT ライセンス · Node 20 以降 · ローカルファイルのみ · 認証情報不要 · 依存パッケージなし

## 試してみる

```bash
npx -y ladon-of-access demo        # 架空データでアクセス権の棚卸し
npx -y olympus-of-migration demo   # 架空データで ERP 移行準備チェック
```

すべてのエージェントに架空ファイルで動く `demo` と、Claude Desktop、Claude Code、Cursor などの MCP ホスト向けの MCP サーバー（`npx -y <agent> mcp`）があります。ツールの一覧は各エージェントの README（英語）をご覧ください。

## ファイルと言語

CSV、TSV、セミコロン・縦線区切りのテキスト、Excel `.xlsx`、JSON、JSONL を読みます。12 のエージェントは、Okta、Microsoft Entra ID、Google Workspace、NetSuite、QuickBooks Online、Xero、Stripe、Shopify、Salesforce、Ramp、米国の銀行など 39 種類のエクスポートを列名で認識します。そのうち 2 種類はベンダーのドキュメントと照合済みです。残りはエクスポートについての知識から作成したもので、実際のアカウントでのテストはまだ行っていません。

日本のシステムから出力したファイルもそのまま読めます：日本語の列名（`伝票番号`、`金額`、`勘定科目`、`仕入先名` など）、Shift_JIS（CP932）、UTF-16、`1,200円`・`￥1,200`・`△300` のような金額、`2026年11月14日`・`2026/11/14`・`令和8年11月14日` のような日付、`株式会社`・`(株)`・半角の `ｶ)` を含む会社名。`--lang ja` を指定すると、承認ページ、Olympus の移行準備状況レポート、Ladon の棚卸しサマリーとエビデンスページが日本語で表示されます。結果、コード、CSV ファイルは英語のままです。

## すべてのエージェントが守るルール

- 未知のツールはブロックされます。既定の判断はブロックです。
- **Auto** は既定でオフで、操作ごとに有効化します。ステップ数と支出の上限、緊急停止があります。
- 本番稼働、権限の削除、個人データの削除、資金の移動、法的拘束力のある送信、本番デプロイは、Auto でも必ず名前のある担当者のクリックが必要です。エージェントの記憶の変更も同じです。
- 記憶を持つエージェント（Olympus と Ladon）は、名前のある担当者が承認した事実だけを使い、どの結果にどの事実を使ったかを示し、チェックを緩める内容は学習できません。
- すべての判断はハッシュチェーンの JSONL 監査ログに記録され、鍵を指定すれば署名されます。
- ファイル内のテキストはデータとして扱います。表計算の数式、生の HTML、ID 内の `../` は出力時に無害化し、AI モデルに向けた文（「ignore previous instructions」など）を含む結果には印を付けます。この印は経験則であり、フィルターではありません。

## できないこと

- ライブ連携ではありません。エクスポートしたファイルを読むだけで、お使いのシステムにログインすることはありません。
- 法務・税務・会計・監査の助言ではなく、何かを認証するものでもありません。
- 完全自律ではありません。上記の操作は毎回担当者を待ちます。
- いずれの国の法令、税制、提出様式についても主張しません。
